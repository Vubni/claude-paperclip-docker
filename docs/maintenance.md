# Устройство и обслуживание

## Как устроена система

| Окно | Где выполняется работа | Данные |
| --- | --- | --- |
| Claude Workspace | Claude Desktop во вкладке Code в Docker | Домашний каталог Linux в томе `claude-english_home` |
| Paperclip Workspace | Сервер, агенты и база в Docker. Интерфейс отображает WebKit на Mac | Том `paperclip-workspace_data`, локальные серверные секреты в Application Support |
| Браузер Paperclip | Firefox ESR в отдельном контейнере по запросу | Временный домашний каталог в памяти, отдельный от профиля Claude |

Графический Claude и сервер Paperclip могут использовать до 1,5 CPU и 6 ГиБ каждый. У браузера Paperclip и вспомогательного shell лимиты по 1 CPU и 4 ГиБ. Контейнеры совместно используют ресурсы виртуальной машины Docker Desktop. Сервер Paperclip слушает на Mac только `127.0.0.1:43107`. Адрес окна и авторизации — `http://localhost:43107`. При запуске лаунчер ждёт успешный ответ `/api/health`. Графические окна используют отдельные порты loopback и случайные токены просмотра.

Claude и Paperclip видят одну папку проектов `/home/developer/projects`. Браузер Paperclip доступа к ней не получает. Для переноса файлов откройте контейнер Claude в Docker Desktop и выберите **Files**. В Linux-окнах доступны ⌘A, ⌘C, ⌘V, ⌘X, ⌘Z, ⇧⌘Z и ⌘F. Текст, скопированный внутри Linux, доступен в буфере Mac при открытом окне просмотра. Закрытие окна оставляет сервис запущенным. Для завершения сеанса браузера, в том числе его временного хранилища, остановите контейнер проекта `paperclip-browser` в Docker Desktop.

Русский включён по умолчанию. Переключатель языка расположен в меню аккаунта Paperclip. Ручной словарь, перевод стартового задания и дополнительный словарь статических подписей находятся в `Paperclip Workspace.source/Contents/Resources/localization/`. Дополнительный словарь подготовлен локально с помощью [Argos EN→RU](https://github.com/argosopentech/argospm-index). Модель при установке не скачивается. Имена, команды и пользовательские тексты сохраняются. Динамические диагностические сообщения, тексты расширений и ответы моделей могут оставаться на языке источника.

## Сеть и обновления

Перед открытием среды проверяется страна выхода с Mac и из Docker. При результате RU, неназначенном коде или неоднозначном ответе запуск блокируется. Эта проверка действует в момент запуска. В обычном режиме эта проверка действует при запуске. Для постоянного контроля доступен строгий профиль ниже. Внешние ссылки требуют явного подтверждения домена и открываются в браузере Paperclip. Ссылки самого Claude обслуживает его собственная среда.

Чтобы обновить установку, выполните `git pull --ff-only` и снова запустите `./Install.command`. Для применения изменений закройте окно и повторно запустите приложение. Сборка повторно использует существующий графический базовый образ, чтобы обновление Paperclip не прерывало сеанс Claude. Для сознательного обновления Linux-клиента после завершения работы выполните `docker --context desktop-linux compose -f "Claude Workspace.source/Contents/Resources/compose.yaml" build --pull --no-cache desktop`. При повторной установке сохраняются имена Compose-проектов и тома. Команды удаления томов стирают данные.

## Близкие проекты

- [Paperclip](https://github.com/paperclipai/paperclip) предоставляет систему работы с агентами и собственное развёртывание в Docker.
- [fjmerc/claude-desktop-docker](https://github.com/fjmerc/claude-desktop-docker) запускает графический Claude Desktop в Ubuntu с доступом через VNC/noVNC.
- [LinuxServer Webtop](https://github.com/linuxserver/docker-webtop) предоставляет универсальный рабочий стол Linux в браузере.

Здесь объединены локальные macOS-лаунчеры, русская сборка Paperclip, отдельный браузер Linux и обмен через подкаталог проектов. В репозиторий входят исходники и сценарий сборки. Образы приложений и данные аккаунтов создаются на компьютере пользователя.

### Проверка перевода

Для закреплённого образа сканер обходит страницы и компоненты в `/app/ui/src`, исключая тесты, демонстрационные макеты и код внутри блоков примеров. Для отчёта со списком статических фраз выполните:

```sh
docker --context desktop-linux build --target ui -t local/paperclip-ui-audit "Paperclip Workspace.source/Contents/Resources/localization"
docker --context desktop-linux run --rm --network none --entrypoint node local/paperclip-ui-audit /app/ui/workspace-localization/static-copy.cjs > ui-inventory.json
```

Ручной словарь — `ru.tsv`, дополнительный — `ru-extra.json`. При следующем обновлении upstream сравните новый отчёт с этими файлами и отдельно проверьте динамические компоненты сервера. Открытие каждой комбинации ролей, расширений и внешних провайдеров на чистом Mac не проверено.

В проверенной версии сканер просмотрел 898 TSX-файлов. В установленном окне на Mac проверены фильтры входящих, карточка первого вопроса, кнопки ответа и отмены, ссылка на исходную задачу и история решений. Проверка Firefox использовала тестовую страницу без авторизации. На отдельном чистом Mac сквозной тест не проводился.

## Модели Codex в Paperclip

Сборка `ui-v6` использует Linux Codex CLI 0.172.0. Во время сборки `build-codex-catalog.cjs` читает `codex debug models --bundled`. Сервер и интерфейс получают из одного каталога видимые модели, порядок, названия, доступные уровни рассуждения и поддержку Fast. Первыми идут GPT-6.2 Sol и GPT-6.2 Astra. Старые идентификаторы Paperclip доступны для существующих настроек. Уровень «Авто» оставляет выбор агенту. В меню под полем сообщения нажатие на название открывает поиск модели, стрелки на клавиатуре меняют уровень, круговая стрелка возвращает настройки агента.

Каталог соответствует версии CLI внутри образа. Когда выходит новая версия, обновите `CODEX_CLI_VERSION` в Dockerfile локализации и пересоберите образ. Кнопка обновления списка перечитывает каталог установленной сборки. Доступность конкретной модели зависит от подключения и тарифа агента. Если администратор задал собственный список через `PAPERCLIP_ADAPTER_MODELS`, Paperclip использует его.

На этом Mac установленный лаунчер прошёл проверки страны выхода и готовности сервера. Серверные функции списка и обновления вернули одинаковые 20 уникальных моделей. Прошли 39 штатных тестов меню. На тестовых данных в Chromium при ширине 375 и 950 пикселей проверены поиск и выбор GPT-6.2, клавиатура, быстрый режим и сброс. В WebKit проверены отрисовка ползунка и переключение между Astra и Sol. Вызовы моделей через платное подключение и доступ по конкретному тарифу не проверялись.
